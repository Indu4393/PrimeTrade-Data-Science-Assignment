# PrimeTrade-Data-Science-Assignment
Analysis of trader performance vs market sentiment (Fear vs Greed)


## Objective
Analyze the relationship between trader performance and market sentiment (Fear vs Greed).

## Datasets
- Historical Trader Data (Hyperliquid)
- Bitcoin Fear & Greed Index

## Key Insights
- Trader profitability and win rate are higher during Greed periods
- Trade sizes and activity increase when sentiment is optimistic
- Fear periods show cautious behavior and lower performance

## Conclusion
Market sentiment significantly influences trader behavior and can be used as a risk-management filter in trading strategies.
